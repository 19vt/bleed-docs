# FAQ

**A command says I have no permission.**
Make sure bleed's role sits in the top five roles, above the roles it needs to
manage.

**How do I change the prefix?**
`,prefix add <new prefix>`. It is per server.

**Where are the settings?**
`,config` in Discord, or the [dashboard](https://bleedrip.vercel.app/manage.html). Both edit
the same values.

**Do I need to run every setup command?**
No. `,setup` is the important one. VoiceMaster, filter, anti-nuke and
tickets are opt-in.

**How do I get support?**
Open a ticket in https://discord.gg/bleed, or use the ticket panel in a server that has one.
