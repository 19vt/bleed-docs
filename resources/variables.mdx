# Variables

Variables work anywhere text is rendered: embeds, welcome and leave messages,
boost messages, invoke messages and the dashboard's embed sender. Run
`,variables` in Discord for the same list, or `,variables test <text>`
to see one rendered with real values.

Unknown variables are left exactly as typed, so a typo stays visible instead of
silently rendering as empty.

## User

| Variable | Renders |
|----------|---------|
| `{user}` | mentions the member |
| `{user.name}` | username |
| `{user.display_name}` | display name |
| `{user.id}` | user id |

| `{user.tag}` | username |
| `{user.nickname}` | nickname in this server |
| `{user.avatar}` | avatar url |
| `{user.display_avatar}` | avatar url |
| `{user.guild_avatar}` | server avatar url |
| `{user.created_at}` | account age, relative |
| `{user.created_at_timestamp}` | account creation, unix |
| `{user.joined_at}` | join date, relative |
| `{user.joined_at_timestamp}` | join date, unix |
| `{user.bot}` | Yes / No |
| `{user.boost}` | Yes / No |
| `{user.boost_since}` | boost date |
| `{user.boost_since_timestamp}` | boost date, unix |
| `{user.color}` | top role colour |
