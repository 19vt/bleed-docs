# bleed

bleed handles moderation, security and the day-to-day utilities a server actually
needs, with every feature configurable per server — from the server itself or from
the [dashboard](https://bleedrip.vercel.app/dash.html).

## What it does

| Area | What you get |
|------|--------------|
| Security | Anti-nuke with per-module punishments, anti-raid lockdown, automod, phishing and invite filtering, quarantine, alt detection |
| Moderation | Ban / kick / mute / jail / warn with cases, notes, hierarchies and a per-server mod log |
| Tickets | A button panel, private channels, claiming, transcripts and the same controls on the website |
| Community | Welcome and leave messages with variables, levels, streaks, giveaways, suggestions, starboard, reaction and button roles |
| Voice | VoiceMaster: a join-to-create hub, an interface channel and per-room controls |
| Utilities | 12 setting groups, 44 custom emojis, everything scriptable with variables |

## Getting started

1. Invite the bot and make sure its role is in the **top five** roles.
2. Run `,setup` — creates the moderation roles, category, jail channel and log channel.
3. Optionally run `,voicemaster setup`, `,filter setup` and `,antinuke setup`.
4. Open `,config` (or the dashboard) for everything else.
