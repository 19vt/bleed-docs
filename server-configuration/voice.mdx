# Voice

15 settings. Change them with
`,config`, or on the [dashboard](https://bleedrip.vercel.app/manage.html).

| Key | Setting | Type | Default | Notes |
|-----|---------|------|---------|-------|
| `vcEnabled` | VoiceMaster enabled | `boolean` | `false` |  |
| `vcHubChannelId` | Hub channel | `channel` | *not set* | Joining this channel spawns a temp voice channel. |
| `vcCategoryId` | Voice category | `channel` | *not set* |  |
| `vcNameTemplate` | Name template | `string` | `{user}'s channel` | Placeholders: {user}, {display}, {count}. |
| `vcUserLimit` | Default user limit | `number` | `0` |  |
| `vcBitrate` | Bitrate (kbps) | `number` | `64` |  |
| `vcDefaultLocked` | Lock new channels | `boolean` | `false` |  |
| `vcDefaultHidden` | Ghost new channels | `boolean` | `false` |  |
| `vcPanelEnabled` | Control panel | `boolean` | `true` | Post the button panel in every temp channel. |
| `vcTrustedRoleIds` | Trusted roles | `list` | *empty* | Roles allowed to manage any temp channel. |
| `vcLogChannelId` | Voice log | `channel` | *not set* |  |
| `vcRegion` | Voice region | `string` | `auto` | auto, or a region like us-east. |
| `vcPanelChannelId` | Panel channel | `channel` | *not set* | Where the Create VC panel was posted. |
| `vcInterfaceChannelId` | Interface channel | `channel` | *not set* | The text channel holding the VoiceMaster interface. |
| `vcPanelMessageId` | Panel message | `string` | *not set* | Message id of the Create VC panel. |

Type: `boolean`.
