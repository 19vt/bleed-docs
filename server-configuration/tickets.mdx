# Tickets

11 settings. Change them with
`,config`, or on the [dashboard](https://bleedrip.vercel.app/manage.html).

| Key | Setting | Type | Default | Notes |
|-----|---------|------|---------|-------|
| `ticketEnabled` | Tickets enabled | `boolean` | `false` | Members can open support tickets. |
| `ticketCategoryId` | Ticket category | `channel` | *not set* | Category new ticket channels are created in. |
| `ticketLogChannelId` | Ticket log | `channel` | *not set* | Closed tickets and transcripts are posted here. |
| `ticketTranscripts` | Save transcripts | `boolean` | `true` | Attach an HTML transcript when a ticket closes. |
| `ticketSupportRoleIds` | Support roles | `list` | *empty* | Roles that can see and answer every ticket. |
| `ticketPanelChannelId` | Panel channel | `channel` | *not set* | Channel the open-a-ticket panel lives in. |
| `ticketPanelMessageId` | Panel message | `string` | *not set* | Message id of the ticket panel. |
| `ticketNameTemplate` | Channel name | `string` | `ticket-{user}` | Placeholders: {user}, {count}, {subject}. |
| `ticketOpenMessage` | Ticket greeting | `string` | `Thanks for reaching out — a member of the team will be with you shortly.` | Posted inside a freshly opened ticket. |
| `ticketAllowMultiple` | Multiple tickets | `boolean` | `false` | Let one member hold more than one open ticket. |
| `ticketPingSupport` | Ping support | `boolean` | `true` | Mention the support roles when a ticket opens. |
