# Automod

Content filters that run on every message before it reaches your members.

| Filter | Catches |
|--------|---------|
| Anti-spam | repeated messages inside a window |
| Anti-invite | Discord invite links |
| Anti-mention | mass mentions |
| Anti-link | links to domains you have not approved |
| Phishing | known phishing patterns |

```bash
,filter setup
```
