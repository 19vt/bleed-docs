## Publishing

These are MDX files with frontmatter and a `docs.json` navigation file, so they
drop straight into Mintlify, or any static MDX host. To publish to a GitHub
repository instead, set `GITHUB_REMOTE` and `GITHUB_TOKEN` and run:

```bash
npm run push:docs
```

55 files are generated per run.
