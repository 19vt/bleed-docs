## ,boost

Manage boost notifications and awards for this server.

**Usage:** `,boost <channel|message|view|settings|test|remove|variables>`
**Aliases:** `boosting`, `boosts`

```bash
{prefix}boost channel #boosts
{prefix}boost message Thanks {mention} for boosting {guild}!
{prefix}boost view
{prefix}boost test
```

## ,invoke

Change what the bot says for mod actions.

**Usage:** `,invoke <message|dm|view|reset|variables> <action> [text]`
**Aliases:** `invokemsg`, `iv`
**Subcommands:** `{prefix}invoke view <action>`, `{prefix}invoke message <action> <text>`, `{prefix}invoke dm <action> <text>`, `{prefix}invoke reset <action|all>`, `{prefix}invoke variables`

```bash
{prefix}invoke view ban
{prefix}invoke message ban You were banned from {guild} by {moderator}.
{prefix}invoke dm mute You were muted in {guild} for {duration}.
{prefix}invoke reset ban
```

## ,reaction

**Usage:** `,reaction <add|edit|rename|move|remove|list|strict|exclusive>`
**Aliases:** `autoreact`, `autoreactions`, `re`, `react`, `reactions`
**Subcommands:** `{prefix}reaction add <name> <trigger> <emoji>`, `{prefix}reaction remove <name>`, `{prefix}reaction rename <name> <new name>`, `{prefix}reaction move <name> [#channel]`, `{prefix}reaction list`, `{prefix}reaction clear`, `{prefix}reaction strict add|remove|list <name>`, `{prefix}reaction exclusive channel|role|list|remove`

```bash
{prefix}reaction add nice good bot :robot:
{prefix}reaction list
{prefix}reaction clear
```

## ,welcome

Set up welcome and leave messages.

**Usage:** `,welcome <message|channel|dm|test|variables|toggle>`
**Aliases:** `greet`, `wlc`
**Subcommands:** `{prefix}welcome message set|preview|remove|leave`, `{prefix}welcome channel add|remove|list|leave`, `{prefix}welcome dm enable|disable|status|message`, `{prefix}welcome test welcome|leave`, `{prefix}welcome on|off`, `{prefix}welcome variables`

```bash
{prefix}welcome message set Welcome {user}!
{prefix}welcome channel add #welcome
{prefix}welcome dm enable
{prefix}welcome test welcome
```
