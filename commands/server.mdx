## ,admin

Admin tools for managing your server.

**Usage:** `,admin <viewwarnings|notes|cleanup|history|recent|announce>`
**Aliases:** `sadm`, `serveradmins`
**Subcommands:** `viewwarnings`, `notes`, `cleanup`, `history`, `recent`, `announce`

```bash
,admin viewwarnings @user
,admin notes add @user broke rules
,admin cleanup roles
,admin recent bans
,admin announce #general hello
```
